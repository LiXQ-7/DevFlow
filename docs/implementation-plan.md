# 实施计划

根据根目录 PRD 实现 V1，采用单 Agent，保留 HelloAgents 的 ReAct 执行循环。

1. S0：固定 Python 3.11、上游 commit，运行 API 探针，记录兼容决策。
2. S1/S2：Pydantic 配置、六工具、路径策略、命令超时与原子写，完成边界测试。
3. S3：结构化状态、Token 预算、输出截断与完整输出留存，测试压缩后的协议完整性。
4. S4/S5：JSONL append-only 树、恢复、分支、持久化压缩，测试故障和副作用不确定性。
5. S6：RuntimeAdapter、Controller、CLI、四 Skills、Trace，运行无网络端到端回归。
6. S7：240 条工具数据、12×20 Context A/B、30 次故障注入、CSV 和报告、演示与接手文档。

代码按上述阶段逐步增加，每阶段执行相关测试。真实模型评测依赖用户配置模型凭据；离线测试必须单独标注，不作为模型准确率。上游代码仅安装为外部依赖，探针检出目录不纳入版本控制。
