## 面试追问

- 为什么保留六工具：给模型稳定、可校验的语义；Bash 是通用出口但结果通常更难约束。
- 如何控制 Token：每次模型请求前计入工具 Schema，限制单次输出并将旧完整轮次抽取成状态摘要。
- 为什么不能只删历史：会丢约束、失败尝试、文件哈希和 TODO；JSONL 原始事件保留，活跃上下文是派生视图。
- 为什么 JSONL Tree：append/fsync 简单可审查，parent_id 支持历史分支；并发写通过文件锁和 expected_last 检测。
- 能保证 exactly-once 吗：不能。工具副作用和日志追加没有共同事务，结果缺失时必须核验实际状态。
- 哪些来自开源：ReAct 主循环和通用基础组件；自研边界与上游实际差异见 ADR。
- 测试数字可信在哪：看模式、数据 SHA256、原始 CSV、错误样本和 API usage；不把无模型测试称为模型准确率。
