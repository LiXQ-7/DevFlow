---
name: debug
description: 复现异常、收集证据、最小修复与回归
---

1. 从用户描述、失败测试、异常栈明确触发条件；缺失证据时先检索，不猜根因。
2. 用 TodoWrite 记录复现、定位、修复、验证步骤，只保留一个进行中状态。
3. Grep 定位错误、调用方和被调用方；Read 只读取相关行并记录哈希。
4. 在获准执行命令后运行最小复现；保留退出码、stderr 和完整输出路径。
5. 把每个失败假设及证据写入可见回答，避免重复尝试；不输出私有思维链。
6. Edit 采用最近 Read 的 expected_hash，发生冲突先重读，不覆盖他人修改。
7. 运行相关回归；未运行或失败必须明确报告，不能把已修改等同于已验证。
